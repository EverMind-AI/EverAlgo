# evercore-user-memory

User-side memory products — `EpisodeExtractor`, `ForesightExtractor`, `AtomicFactExtractor`, `ProfileExtractor`. Re-exports `ChatMemCellExtractor` / `WorkspaceMemCellExtractor` from `evercore-boundary` for facade convenience.

See the umbrella project: [EverCore monorepo](../../README.md) and the architecture document at [`docs/design.md`](../../docs/design.md).

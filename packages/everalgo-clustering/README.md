# everalgo-clustering

Online incremental clustering — `cluster_by_geometry` / `cluster_by_llm` public functions over a frozen `ClusterState` value object (centroids / counts / last_ts). Stateless, caller-owned persistence.

See the umbrella project: [EverAlgo monorepo](../../README.md) and the architecture document at [`docs/design.md`](../../docs/design.md) §2.4.

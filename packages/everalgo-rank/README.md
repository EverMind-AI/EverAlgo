# everalgo-rank

Memory ranking — 4 business-facing rankers (`episodic` / `profile` / `case` / `skill`) composed over a shared toolkit (`fusion` / `weight` / `rerank`). Pure in-memory rank, no storage I/O.

See the umbrella project: [EverAlgo monorepo](../../README.md) and the architecture document at [`docs/design.md`](../../docs/design.md).
